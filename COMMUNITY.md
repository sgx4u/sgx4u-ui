## 💎 What is @sgx4u/ui?

`@sgx4u/ui` is not a black-box design system. It is:

- **Readable source code** — no hidden abstractions
- **Accessible by default** — proper ARIA, semantics & keyboard support
- **TypeScript-first** — predictable, fully typed APIs
- **Tailwind-based** — utility-first styling with escape hatches
- **CLI-driven** — inspect, add, and manage components instantly

Whether you're building a small prototype or a large-scale production app, this library is designed to scale with you.

## ⚡Philosophy of This Project

SGX4U UI is built around one core belief: Developers should never fight their UI library.

- You install real source code.
- You see everything.
- You control everything.

No magic. No opaque abstraction layers. Just scalable, accessible, production-ready primitives.
